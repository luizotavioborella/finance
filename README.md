# 💰 Finance

A financial management system developed with HTML, CSS and JavaScript to organize income, expenses and financial transactions.

This project was developed as a group activity during the Systems Development course at SENAI, with the goal of applying JavaScript concepts in a functional web application.

## ✨ Features

- Add income and expenses
- View financial transactions
- Calculate total income and expenses
- Display the available balance
- Delete transactions
- Transaction history
- Light and dark themes
- Responsive interface
- Data stored with localStorage
